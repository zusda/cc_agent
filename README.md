# cc_agent

A personal single-agent framework. It isolates data per user and supports session history (with automatic compression), model configs, MCP tools, and Skills.

## Documentation

For the components and how to use them, see the [blog](https://zusda.github.io/2026/11/06/ai%E5%BC%80%E5%8F%91%E7%AF%87-1-%E5%88%B6%E4%BD%9Cagent/).

## Prerequisites

- Python 3.x
- A local Ollama instance (or rewerite your own model)
- Tools are provided by MCP servers, so start your MCP server first
